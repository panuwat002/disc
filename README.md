# แบบประเมินพฤติกรรม DISC

แบบประเมินพฤติกรรมออนไลน์ 37 ข้อ ภาษาไทย ไฟล์เดียวจบ ไม่ต้องมีเซิร์ฟเวอร์

## ลิงก์ใช้งาน

| ใช้กับใคร | ลิงก์ |
|-----------|-------|
| พนักงานปัจจุบัน | `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` |
| ผู้สมัครงาน | `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/?for=applicant` |

## ความสามารถ

- คำถาม 37 ข้อ ทีละข้อเต็มหน้าจอ มีแถบความคืบหน้า ย้อนกลับแก้ได้ กดเลข 1–4 แทนได้
- สลับลำดับตัวเลือกใหม่ทุกครั้ง กันการกดรวดเป็นแนวเดียว
- บันทึกผลเข้า Google Sheets อัตโนมัติ พร้อมรองรับการนำเข้า–ส่งออกไฟล์ Excel (`.xls` / `.xlsx`) ทั้งชุดคำถามและข้อมูลผลประเมิน
- **โหมดพนักงาน** เห็นผลตัวเอง สไตล์หลัก สไตล์รอง คะแนนทั้ง 4 ด้าน จุดแข็ง จุดที่ควรระวัง
- **โหมดผู้สมัครงาน** เห็นแค่หน้าขอบคุณ ผลไปโผล่ที่ฝ่ายบุคคลพร้อมประเด็นที่ควรถามในสัมภาษณ์
- รองรับมือถือ และปรับตามธีมสว่าง/มืดของเครื่องผู้ใช้

## การคิดคะแนน

ไฟล์นี้ **ไม่มีเฉลย** ว่าตัวเลือกไหนนับเป็น D / I / S / C มีแต่ข้อความคำถาม

เวลาส่งข้อมูลจะส่งแค่ว่าแต่ละข้อกดตัวเลือกลำดับที่เท่าไหร่ (`picks`) แล้วให้ Google Apps Script เป็นคนแปลงเป็นคะแนนและส่งผลกลับมา เฉลยอยู่ฝั่ง Google ที่เดียว

ทำแบบนี้เพื่อให้ใช้กับผู้สมัครงานได้โดยที่เปิด View Source แล้วเดาทางตอบไม่ได้

## การตั้งค่า

แก้ได้ในบล็อก "ตั้งค่า" บนสุดของ `<script>` ใน `index.html`

| ตัวแปร | ใช้ทำอะไร |
|--------|-----------|
| `ENDPOINT` | URL ของ Google Apps Script ที่ deploy แล้ว |
| `DEPARTMENTS` | รายชื่อแผนก (โหมดพนักงาน) ถ้าเว้นว่างจะเป็นช่องพิมพ์เอง |
| `JOBS` | รายชื่อตำแหน่งที่เปิดรับ (โหมดผู้สมัคร) |
| `EMPLOYEE_FIELDS` / `APPLICANT_FIELDS` | ข้อมูลที่ขอจากผู้ตอบในแต่ละโหมด |
| `CONSENT_EMPLOYEE` / `CONSENT_APPLICANT` | ข้อความขอความยินยอมตาม PDPA |

ส่วนโค้ดฝั่ง Google Apps Script กับคู่มือติดตั้งไม่ได้อยู่ใน repo นี้ เก็บไว้ภายในองค์กร

## ข้อจำกัดที่ควรรู้

แบบประเมินชุดนี้รวบรวมจากเอกสารภายใน ยังไม่ได้ผ่านการตรวจสอบความเที่ยงตรงทางสถิติ เหมาะกับการทำความเข้าใจตัวเองและใช้ตั้งคำถามในการสัมภาษณ์ **ไม่เหมาะกับการใช้เป็นเกณฑ์ตัดสินรับเข้าทำงานหรือเลื่อนตำแหน่ง**
